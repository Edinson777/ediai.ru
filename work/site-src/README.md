# «База промптов для ИИ» — многостраничник (светлая тема)

Готовый к публикации сайт лежит в **`../site/`**. Исходники и генератор — здесь (`work/site-src/`).
Домен: **ediai.ru** (прописан в `config.json` → canonical, OG, sitemap, robots).

## Дизайн

- **Светлая тема**: фон `#f5f6fa`, белые карточки с мягкими тенями, акценты — фиолетовый `#6a5ae0` и циан `#0e7490` (текстовые варианты подобраны под WCAG AA: контраст мелкого текста 4.9–6.1:1).
- **Источники — под спойлером**: блок «Источники» на всех страницах свёрнут в `<details>/<summary>` (контент остаётся в DOM и индексируется поисковиками).
- Тост-уведомления оставлены тёмными — так они заметны на светлом фоне.

## Мобильная вёрстка (проверено в headless Chromium)

Замеры на 390×844 и 360×740: горизонтальных переполнений нет; липкая панель фильтров —
203–206 px (24% экрана) в свёрнутом состоянии, включая строку чипов-ограничений. Подразделы на мобильных открываются
плавающим дропдауном (не растягивает панель, закрывается после выбора), на десктопе —
одна скроллящаяся строка с fade-краем (панель 199 px / 22%). Поле поиска 16 px (iOS не зумит),
промпты без «скролла в скролле». Скриншоты и замеры: `tmp/shots.py` → `tmp/shots/*.png`.

## Что вшито из P0

- Мета-теги: `description`, `og:*` + `twitter:*` (со светлыми картинками), `canonical` на ediai.ru, `theme-color:#f5f6fa`, SVG-favicon.
- SEO без JS: все 211 карточек отрендерены статически; `<noscript>` раскрывает их и прячет нерабочие контролы; JSON-LD (WebSite, CollectionPage, ItemList, FAQPage).
- A11y: контраст AA, aria-label/aria-live/aria-controls/aria-expanded/aria-pressed, skip-link, focus-visible, prefers-reduced-motion, aria-hidden на декоративных SVG.
- UX: «Свернуть все» не стирает поиск; кнопка «Копировать» не перекрывает текст; deep-link `photo.html?q=…`.
- **Яндекс.Метрика подключена** (ID 114035585): сниппет сразу после `<body>` на всех страницах (webvisor, clickmap, ssr). События `app.js`: `prompt_copy` и `empty_search` — создайте для них цели типа «JavaScript-событие» в интерфейсе Метрики.
- **Контентная аналитика Метрики**: каждый из 211 промптов размечен как отдельный материал `Article` (JSON-LD: `@id` = якорь карточки, `headline`, `articleBody` — обязательные элементы Метрики; плюс description, dates, keywords). После выкладки сайта и накопления данных в отчётах появятся доскроллы/дочтения по каждому промпту. Microdata не дублируется намеренно: Метрике достаточно одного синтаксиса, JSON-LD — рекомендованный.
- **Google Analytics 4 — готово, ждёт ID**: поддержка встроена в сборку, но по умолчанию отключена (`ga_id: ""` в `config.json` → сниппет gtag.js не вставляется, лишних запросов нет). Как только впишете Measurement ID, GA4 заработает автоматически — см. ниже.

## Автореклама Яндекс РСЯ

Сниппет авторекламы (блок из кабинета РСЯ) встраивается сборкой перед `</body>` на всех
страницах: `context.js` + `ap-loader.js` с `data-page-id`, оба `async` — первый рендер и
 счётчики не блокируются. Номер блока берётся из `config.json` → `ads_block_id`
(сейчас `20335162`); пустое значение — сниппет не вставляется вовсе. Рекламные блоки
загрузчик вставляет сам в поток контента; после запуска проверьте в браузере, что блоки
не наезжают на липкую панель фильтров и карточки (при проблемах — точечные отступы в CSS).

## Фильтры-ограничения, глобальный поиск, статьи-кейсы (этап 3 стратегии)

- **Чипы «бесплатно / нужно фото-файл / 5 минут»** (`ftags()` в `build.py`): выводятся из данных
  карточки (`model`, `section`, `cat`/`sub`, `ds`), без ручной разметки 211 промптов. Чип рендерится
  в разделе, только если отсекает часть карточек (0 < n < всего); в `app.js` несколько чипов
  работают как «И». Счётчики на чипах — статические, совпадают с JS-фильтрацией.
- **Глобальный поиск на главной**: `build.py` встраивает компактный индекс `SIDX`
  (id, заголовок, раздел, подраздел, описание, теги — без текстов промптов, ~40 КБ) и код `hub.js`;
  результаты — ссылки `раздел.html#pN`, раздел раскрывает карточку по якорю (`app.js`).
  Без JS поиск скрыт, все промпты доступны через разделы. Пустая выдача шлёт `empty_search`.
- **Статьи-кейсы**: шаблон серии зафиксирован в комментарии у констант `KEIS_*` (`build.py`):
  hero → «Коротко» → таблица исследований → иллюстративный расчёт → промпты-шаги `.gstep`
  со ссылками `#pN` → warn-strip → чек-лист (HowTo) → баннер раздела → спойлер источников.
  Цифры — только из опубликованных исследований со ссылкой либо явно помеченный расчёт.
  Новая статья = новые константы + `w(KEIS_FILE, know_case())` в `main()`, плюс OG-спека,
  sitemap и карточка в блоке «Статьи и кейсы» главной.

## Google Analytics 4 (включение за 2 минуты)

1. Откройте [analytics.google.com](https://analytics.google.com) → «Администратор» → создайте аккаунт/ресурс (или используйте существующий ресурс).
2. В ресурсе: «Администратор» → «Потоки данных» → «Веб» → укажите `https://ediai.ru` → скопируйте **Measurement ID** вида `G-XXXXXXXXXX`.
3. Впишите его в `work/site-src/config.json`: `"ga_id": "G-XXXXXXXXXX"`.
4. Пересоберите и выкатите: `python3 build.py` → коммит и пуш → кнопка FTP-деплоя в Actions.

Что происходит после этого автоматически:

- На всех 6 страницах после `<body>` (рядом с Метрикой) появляется официальный сниппет `gtag.js` (`googletagmanager.com/gtag/js?id=G-…` + `dataLayer`/`config`).
- События `prompt_copy` и `empty_search` дублируются в GA4 через `gtag('event', …)` — в GA4 они попадают в раздел «Анализ» → отчёты по событиям (дополнительные цели создавать не нужно; при желании событие `prompt_copy` можно пометить как ключевое в «Администратор» → «События»).
- Параметры `title` и `section` у событий — если нужны в отчётах GA4, зарегистрируйте их как пользовательские параметры: «Администратор» → «Определения данных» → «Пользовательские параметры» → «Размеры событий».
- Проверка: расширение Chrome **Google Analytics Debugger** или Realtime («Время в реальном времени») — откройте сайт, скопируйте промпт, событие появится в течение секунды.

## Как править

1. **Промпты:** `work/site-src/data.json`.
2. **Заголовки/описания/баннеры/источники:** `work/site-src/build.py` (словари `SECTIONS`, `TILES/STEPS/POPULAR/FAQ`).
3. **Дизайн:** `work/site-src/style.css`. **Поведение:** `work/site-src/app.js`.
4. **Домен/даты/счётчики:** `work/site-src/config.json` (`site_url`, `updated`, `metrika_id`, `ga_id`).

Сборка и тесты:

```bash
cd work/site-src && python3 build.py            # пересборка ../site/ (+ OG-картинки, нужен Pillow)
cd tmp && npm install jsdom && node smoke.js          # функциональные тесты (jsdom)
pip install playwright && playwright install chromium --only-shell \
  && playwright install-deps chromium && python3 shots.py  # скриншоты и замеры вёрстки
```

## Публикация

Залейте содержимое `site/` на любой статический хостинг (Cloudflare Pages, Netlify,
GitHub Pages, shared-hosting). После загрузки: Яндекс.Вебмастер + Google Search Console,
указать `https://ediai.ru/sitemap.xml`.

🤖 Qwen Chat: формулы и режимы

Официальная формула Qwen (6 блоков)

Qwen Chat / APIDeepSeek ✓

Документированный Alibaba фреймворк: шесть именованных блоков с #-разделителями. Работает и в chat.qwen.ai, и через API.

#Context#
[ситуация и данные, которые модель не может угадать: предыстория, ограничения]

#Objective#
[одна задача в повелительной форме: что именно сделать]

#Style#
[стиль изложения: деловая статья / разговорный пост / научный обзор]

#Tone#
[тональность: формальная / дружелюбная / уверенная / поддерживающая]

#Audience#
[кто читает результат: что уже знает, чего ожидает]

#Response#
[точный формат ответа: структура, объём, таблица/список/текст]
💡 Alibaba оговаривает: не каждой задаче нужны все шесть блоков — адаптируйте под задачу. Блоки данных внутри промпта отделяйте редкими разделителями: ###, === или >>>. Это прямой аналог фреймворка CO-STAR.
#qwen#формула#co-star#официальный гайд

Режимы мышления: /think и /no_think

Qwen Chat / APIDeepSeek: аналог

Гибридные модели Qwen умеют «думать» перед ответом. Включайте режим для сложных задач и выключайте для быстрых.

Для сложных задач (анализ, расчёты, архитектура, планирование):
/think
[задача]

Для простых задач (перевод, переформулировка, короткий ответ):
/no_think
[задача]
💡 Через API переключатель — параметр enable_thinking: true/false (в OpenAI-совместимых SDK передаётся внутри extra_body), а рассуждения модели возвращаются в отдельном поле reasoning_content. В Qwen Chat выбор режима (auto / thinking / fast) есть прямо в интерфейсе.
#qwen#thinking#режимы#api

Анализ огромного документа (1M контекст)

Qwen Chat / APIDeepSeek: 128K

Хостовые модели Qwen принимают до ~1 млн токенов — целые книги, отчёты и кодовые базы за один запрос.

Я передаю тебе документ:
===[вставить текст или прикрепить файл]===

Выполни по порядку:
1. Резюме сути в 5 предложениях;
2. Таблица ключевых фактов, цифр и выводов;
3. Найди противоречия, слабые аргументы и пробелы в материале;
4. Ответь на мои вопросы по тексту: [вопросы];
5. Что стоит изучить дополнительно по этой теме.

Правило: ничего не додумывай — если ответа нет в документе, прямо скажи об этом.
💡 Для сверхдлинных документов просите отвечать по разделам с цитатами-привязками — так проще проверять, что ИИ не «поплыл».
#qwen#контекст#документы#анализ

Контроль языка ответа

Qwen Chat / APIDeepSeek ✓

Qwen полиязычен и иногда «соскальзывает» на английский или китайский. Официальная рекомендация — вынести язык в отдельный именованный блок.

#Language#
Всегда отвечай на русском языке. Технические термины можно оставлять в оригинале, но при первом упоминании давай перевод в скобках.

#Objective#
[ваша задача]

#Response#
[формат ответа]
#qwen#язык#русский#локализация

Строгий JSON для интеграций

Qwen APIDeepSeek: V3

Структурированный вывод для скриптов, ботов и автоматизации — без лишнего текста вокруг.

Отвечай ТОЛЬКО валидным JSON, без комментариев и markdown-обёрток.

Схема: объект "result" содержит массив "items"; каждый элемент: "title" (строка), "summary" (строка до 200 знаков), "tags" (массив строк), "score" (число от 1 до 10).

Задача: [что проанализировать и разложить на элементы].
Данные: ===[данные]===

Важно: ответ должен быть JSON от первого до последнего символа.
💡 Через API включите response_format: json_object (слово JSON обязательно должно встречаться и в самом промпте) или json_schema с strict: true — тогда схема гарантируется на уровне движка.
#qwen#json#api#автоматизация#код

Исследование темы (Deep Research)

Qwen ChatDeepSeek ✓

Глубокий разбор темы с оценкой достоверности. В Qwen Chat для этого есть режим Deep Research — промпт даёт тот же результат в обычном чате.

Проведи исследование темы «[тема]».

1. Разбей тему на 4–6 подвопросов и перечисли их;
2. Ответь на каждый: данные, примеры, альтернативные точки зрения;
3. Пометь каждый вывод уровнем достоверности: факт / вероятное суждение / гипотеза;
4. Отдельно — что осталось спорным или непроверенным;
5. Финал: 5 главных выводов и рекомендации, что изучить дальше.

Формат: структурированный отчёт с заголовками, без воды.
#qwen#research#исследование#анализ#достоверность

Веб-приложение одним файлом (Artifacts)

Qwen ChatDeepSeek ✓

Qwen Chat умеет сразу собирать работающие приложения (режимы Artifacts / Web Dev). Промпт для качественного результата с первого раза.

Создай веб-приложение в одном файле: [что за приложение, например «трекер привычек»].

Требования:
- HTML + CSS + JavaScript в одном файле, без внешних библиотек и CDN;
- Функциональность: [список функций по пунктам];
- Данные сохраняются в localStorage браузера;
- Современный минималистичный дизайн, тёмная и светлая темы, адаптив под смартфон;
- Интерфейс полностью на русском языке;
- Обработай пустые состояния и ошибки ввода.

После кода — короткая инструкция, какие константы в начале скрипта можно настроить под себя.

🤖 Qwen-Coder: код

Фича: код + тесты + обоснование

Qwen-Coder / любая LLMDeepSeek ✓

Разработка по-взрослому: код по конвенциям проекта, unit-тесты с краевыми случаями и объяснение решений.

Действуй как senior [язык/стек]-разработчик.

Задача: реализовать [функция/фича] в [проект/файл].
Контекст: [стек, соглашения проекта, ограничения, как устроен соседний код].

Выдай по порядку:
1. Код по конвенциям проекта ([именование, стиль, структура]);
2. Unit-тесты: основные случаи + минимум 3 краевых;
3. Обоснование архитектурных решений: почему так и какие были альтернативы;
4. Чек-лист: что обновить в зависимых файлах и что проверить вручную.

Не переписывай код, не относящийся к задаче. Если ТЗ допускает двоякое толкование — сначала задай уточняющие вопросы.
💡 Qwen3-Coder создан для агентной работы с целым репозиторием (контекст 256K токенов, расширяется до 1M через YaRN): в Qwen Code CLI дайте ему доступ к проекту и описывайте задачу на уровне цели — он сам найдёт нужные файлы.
#qwen-coder#код#тесты#разработка

Поиск корневой причины бага

Qwen-Coder / любая LLMDeepSeek ✓

Диагностика от симптома к первопричине: минимальный фикс + регрессионный тест.

Найди причину бага и исправь её.

Симптом: [что происходит: ошибка, стектрейс, неожиданное поведение].
Ожидаемое поведение: [как должно быть].
Когда появилось: [после какого изменения, если известно].
Код: ===[вставить код / фрагменты файлов]===

Порядок работы:
1. Проследи путь данных от входа до места падения;
2. Назови КОРНЕВУЮ причину, а не симптом;
3. Минимальный фикс — ничего постороннего не рефакторь;
4. Регрессионный тест: падает на старом коде, проходит на новом;
5. Где ещё в кодовой базе может быть такая же проблема.
#qwen-coder#баг#отладка#тесты

Код-ревью с приоритетами

Qwen-Coder / любая LLMDeepSeek ✓

Структурированный отчёт по серьёзности: баги, безопасность, производительность, читаемость.

Проведи код-ревью:
===[код]===

Контекст: [что это за код, где запускается, требования к надёжности].

Формат отчёта — замечания по категориям, каждое с важностью (критично / важно / мелочь):
1. Баги и необработанные краевые случаи;
2. Безопасность: инъекции, утечки данных, небезопасные зависимости;
3. Производительность: сложность алгоритмов, память, лишние запросы;
4. Читаемость и сопровождаемость.

Для каждого замечания: место (функция/строка), в чём проблема, как исправить — с примером кода.
В конце: общая оценка и топ-3 приоритетных правок. Стиль, который проверяет линтер, не комментируй.
#qwen-coder#ревью#безопасность#качество

Безопасный рефакторинг

Qwen-Coder / любая LLMDeepSeek ✓

Поведение не меняется: сначала характеристические тесты, потом маленькие шаги с подтверждениями.

Отрефактори код:
===[код]===

Цель: [улучшить читаемость / убрать дублирование / разбить класс-монолит / подготовить к расширению].
Ограничение: внешнее API и наблюдаемое поведение не меняются.

Порядок:
1. Характеристические тесты, фиксирующие ТЕКУЩЕЕ поведение (включая его странности);
2. План рефакторинга: маленькие шаги, после каждого все тесты проходят;
3. Выполняй по одному шагу за раз, показывая код после каждого;
4. Финал: итоговая версия и что улучшилось (дублирование, связность, размер функций).

Шаг 1 и план выдай сразу, дальнейшие шаги — по одному, дожидаясь моего подтверждения.
#qwen-coder#рефакторинг#тесты#пошагово

Миграция кода и апгрейд стека

Qwen-Coder / любая LLMDeepSeek ✓

Переезд на новую версию языка или фреймворка — поэтапно, от низкого риска к высокому.

Спланируй и начни миграцию: [откуда → куда: Python 2→3 / JS→TypeScript / Vue 2→3 / старый фреймворк → новый].

Код: ===[код или структура файлов]===
Зависимости: [список с версиями].

Выполни только шаг 1 и остановись — жди подтверждения перед следующим.
